GoodsRun (굿즈런)

누적 조회수 불러오는 중

프로젝트 소개

GoodsRun은 무신사 스타일의 감각적인 UI와 부드러운 애니메이션을 결합한 한정판 굿즈 이터머스 플랫폼입니다. 핵심 기능에 집중하여 빠르고 직관적인 쇼핑 경험을 제공하며, 서버 단의 철저한 시간 검증을 통해 공정한 한정판 타임 드롭(Limited Drop) 시스템을 구현했습니다.

주요 기능

  • 한정판 타임 드롭 & 서버 검증: 오픈 시간을 실시간 카운트다운 타이머로 제공하며, 백엔드 단에서 오픈 시간 전의 비정상적인 구매 요청을 원천 차단합니다.
  • 상품 후기 및 찜(좋아요) 시스템: 5점 만점 별점 평가와 20자 이상 작성 검증이 포함된 무신사 스타일 후기 작성 및 찜 리스트 연동 기능을 제공합니다.
  • 최근 본 상품 & 마이페이지 연동: localStorage를 활용한 최근 본 상품 기록과 사용자의 주문 내역 및 후기 작성 페이지를 다이나믹 라우팅으로 연결합니다.
  • 관리자 상품 관리: 관리자 페이지를 통해 상품 등록, 수정, 삭제 및 드롭 시간 설정 등 플랫폼 운영을 유연하게 제어할 수 있습니다.

사용 기술

Backend: Java, Spring Boot, Spring Data JPA, MySQL, AWS EC2
Frontend: React, Vite, Tailwind CSS / Custom CSS, Vercel
역할: Spring Boot 기반 백엔드 REST API 설계 및 비즈니스 로직(주문, 드롭 검증 등) 구현, React 프론트엔드 UI 컴포넌트 개발 및 Vercel/EC2 배포 연동

팀 소개

팀원: 민규 (Full-stack Developer)
역할: 굿즈런 플랫폼 기획, 프론트엔드 UI/UX 구현, 백엔드 서버 구축 및 데이터베이스 연동 총괄
